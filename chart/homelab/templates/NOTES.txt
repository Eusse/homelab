A post-install Job ("secret-sync") just pulled/generated each enabled app's API
key and pushed it to Infisical (project {{ .Values.infisical.projectId }},
env "{{ .Values.infisical.environmentSlug }}"). Check its logs if Homepage's
widgets come up without data:

  kubectl -n {{ .Release.Namespace }} logs job/secret-sync

The Infisical Operator then syncs those keys back into the "homepage-api-keys"
Secret (see: kubectl -n {{ .Release.Namespace }} get infisicalsecret) which
Homepage reads on a {{ .Values.infisical.resyncInterval }}s interval — allow a
minute after first install for widgets to populate.
